# Trigo Quest v3 — Animated Arcade Edition

Browser-only NCERT Class 10 Chapter 8 game.

Features:
- 100-question master bank; 20 random questions per run
- CSS/JS animated characters and arcade arena
- Target-shooting gameplay (educational, non-violent target mechanic)
- World map and zone progression UI
- 60-second timer, 3 lives, XP, coins, streaks, checkpoints
- Wrong-answer Concept Lab with NCERT reference
- Trigo Boss battle
- LocalStorage leaderboard
- GitHub Pages compatible; no backend/assets required
