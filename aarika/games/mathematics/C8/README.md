# Trigo Quest — NCERT Class 10 Chapter 8

Roblox-inspired educational browser game for CBSE-level Introduction to Trigonometry.

## Contents
- 100-question master bank
- 20-question randomized adventure per playthrough
- 5-question boss battle
- 60-second timer
- 3 lives
- XP, coins, streaks and checkpoints
- Wrong-answer Concept Repair Zone
- Every question has topic/subtopic/difficulty and NCERT chapter reference
- Mobile responsive
- GitHub Pages compatible

## Run
Open `index.html` in a modern browser, or upload all files to a GitHub Pages repository.

Source alignment is based on the uploaded NCERT Mathematics Chapter 8 PDF (2026-27 reprint), including Sections 8.1–8.5 and Exercises 8.1 and 8.3.


## Local Leaderboard v2
The leaderboard uses browser `localStorage`. It stores up to 100 player records on the current browser/device. No Firebase or server is required.
