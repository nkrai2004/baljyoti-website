CENTRAL DATA CONTROL

Master Data & Daily Uploads

One verified school record connects every module. Master records are created once; daily ERP sheets refer to those records through stable IDs. This interface is for authorised ERP users—there are no exposed Google Sheet links.

Master DataStudents · Employees · Parents · Classes · Sections · Subjects · Activities
Daily OperationsAttendance · Timetable · Homework · Assessments · Activity logs
Data GovernanceValidation · Duplicate checks · Approval · Audit trail

Upload a data sheet

Choose the sheet type, then upload a CSV exported from Excel or Google Sheets. The spreadsheet is treated as an upload file only; staff do not need access to the underlying Google Sheet.

Staging safeguard: This first release validates and previews uploads in the browser. It does not write student, employee or daily operational records to Firestore. Persistent import will be enabled only after the staging security rules and approval workflow are reviewed.

How records connect

PeopleStudent ID / Employee ID / Parent ID remain stable across modules.
Academic structureAcademic Year → Class → Section → Subject / Activity.
Daily sheetsAttendance, timetable and activity uploads reference the master IDs—not repeated names alone.

Recommended upload order: Academic Year and Classes/Sections → Subjects and Activities → Employees and Students → Parent Links → Teacher/Activity Assignments → Daily operational sheets.
