Individual module permissions

Keep the role's standard access, then add or remove specific modules for one person. These settings control module entry only. Student, parent, class, fee, HR and other record-level permissions remain governed by separate Firestore rules.

Allow: add module access beyond the roleDeny: remove module access from the role

Choose module exceptions

A module cannot be both allowed and denied. Super Admin permissions cannot be overridden here.

Select a user to load permissions.

Every save is recorded in the audit log. Changes apply on the user's next page load/sign-in. Do not use module access as a substitute for record-level data rules.
