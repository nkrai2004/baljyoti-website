# AARIKA Super Admin — Final Demo Package

## Upload
Upload the **contents of this folder** to the GitHub Pages `/aarika/` directory.

Expected URL:
https://www.baljyoti.com/aarika/

The root `index.html` is the login page.

## Important
- Keep the `pages`, `js`, `css`, and `firebase` folders in the same relative structure.
- Google OAuth is configured for the Bal Jyoti demo client already present in `index.html`.
- The current package contains the cumulative Super Admin UI and functional browser-persistent modules developed so far.
- Data in browser-persistence modules is stored in localStorage for demo purposes; production multi-user data should use Firebase/Firestore.

## Quick test
1. Open `/aarika/`
2. Sign in with an authorised `@baljyoti.com` account.
3. Open Dashboard.
4. Test left menu.
5. Test Add / View / Edit on each completed module.
6. Test mobile menu on iOS/Android-sized screens.
